Bitácora — BLE HID + R200 en la Pi

Notas técnicas. Guías paso a paso: CONEXION_BLUETOOTH_HID.txt, AUTOSTART_HID.txt, PI_BLE_HID.txt.

Objetivo

  La Pi con R200 se comporta como teclado BLE: el EPC se “teclea” en Windows (Bloc de notas, web, etc.).

Origen

  Demo MIT HeadHodge (Bluez-HID-over-Gatt-Keyboard-Peripheral). Referencia: docs/gattServer_upstream.py. Producción: pi_ble_hid/gatt_server_rfid.py.

Stack

  BlueZ, D-Bus, Python 3 (dbus, gi), pyserial. Driver R200 en rfid_inventory/vendor/rfid_r200.

Systemd (orden)

  rfid-hid-bt-up.service — bluetoothctl visible antes del GATT.
  rfid-hid-gatt.service — gatt_server_rfid.py, variables en /etc/default/rfid-hid-gatt.
  Opcional: rfid-hid-bt-up-post.service, rfid-hid-btmgmt-after-gatt.service, timer btmgmt-refresh.

  Rutas en el repo: /home/user/... Edita en /etc si tu usuario es otro.

rfid-hid-bt-up.sh

  power/discoverable/advertise vía bluetoothctl. En esta Pi btmgmt a veces se bloquea; el script no depende de él. Ver journalctl -t rfid-hid-bt-up -b.

Comandos útiles

  sudo bluetoothctl discoverable on
  sudo btmgmt -i hci0 info
  sudo hciconfig hci0 class 0x000540
  journalctl -u rfid-hid-gatt.service -b --no-pager
  sudo pkill -f gatt_server_rfid.py

Windows

  LE Explorer suele funcionar mejor que Ajustes → Agregar Bluetooth. Reconexión tras reinicio no siempre es automática.

Git

  Desarrollo en PC, en la Pi: git pull. Tras cambiar unidades en /etc: systemctl daemon-reload.
