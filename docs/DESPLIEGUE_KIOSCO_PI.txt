Despliegue en Raspberry Pi (kiosco)

Objetivo: al iniciar sesión solo se abre la app a pantalla completa, sin barra de cerrar en la ventana, y sin el panel del sistema (Wi‑Fi, reloj, menú).

Requisitos: Pi OS con escritorio, repo en la Pi, venv en la raíz (Bookworm no deja pip global).

1. Entorno virtual

  sudo apt-get install -y python3-venv python3-full
  cd /ruta/al/Sistema_inventario_RFID
  python3 -m venv .venv
  .venv/bin/pip install -r requirements.txt

  Si tu venv tiene otro nombre: ln -sfn venv .venv
  O export RFID_PYTHON=/ruta/al/repo/venv/bin/python

  launch-handheld.sh usa .venv/bin/python si existe.

2. Probar (importante: con --kiosk)

  chmod +x deploy/raspberry-pi-recortado/launch-handheld.sh
  ./deploy/raspberry-pi-recortado/launch-handheld.sh

  O: .venv/bin/python -m rfid_inventory.ui.gui.handheld_app --kiosk

  Si abres solo "python -m ... handheld_app" SIN --kiosk, verás una ventana
  chica 480x320 en el centro del escritorio (como en Pi Connect). Eso es normal.

  En Linux, --kiosk maximiza la ventana (modo estable). La barra del SO solo se
  quita comentando @lxpanel-pi (paso 4).

  Si parpadea o se traba (sobre todo en Pi Connect):
  - No abras la app dos veces (revisa autostart en ~/.config/autostart/).
  - Mata instancias viejas: pkill -f handheld_app
  - El script launch-handheld.sh ya evita doble instancia (flock).

  Pantalla Waveshare 3.5" sin barra de ventana (cuando la tengas):
  export RFID_KIOSK_BORDERLESS=1
  ./deploy/raspberry-pi-recortado/launch-handheld.sh

  Prueba final en la pantalla física de la Pi, no solo por Pi Connect.

3. Autostart

  Edita deploy/raspberry-pi-recortado/com.rfid-inventario.handheld.desktop
  y cambia /REEMPLAZAR_RUTA_AL_REPO por tu ruta real.

  mkdir -p ~/.config/autostart
  cp deploy/raspberry-pi-recortado/com.rfid-inventario.handheld.desktop ~/.config/autostart/
  chmod +x deploy/raspberry-pi-recortado/launch-handheld.sh

  Cierra sesión y entra de nuevo.

4. Quitar la barra de la Pi

  La app no puede ocultar el panel superior; hay que desactivarlo.

  nano ~/.config/lxsession/LXDE-pi/autostart

  Comenta la línea @lxpanel-pi (pon # al inicio). Guarda y vuelve a iniciar sesión.

  Si tu imagen usa otro panel, revisa la doc de tu versión de Pi OS.

5. Teclado en pantalla (el de Pi OS)

  Actívalo en Control Centre → Display.

  Tkinter NO avisa al teclado del sistema al hacer foco (no usa AT-SPI como
  Chromium o el bloc de notas). Por eso no “sale solo” aunque el campo sí tenga
  foco. Si abres el teclado a mano y escribes, funciona: el problema no es la app,
  es que el SO no enlaza auto-mostrar con ventanas Tk.

  La app, al enfocar un campo de texto, pide mostrar squeekboard (busctl
  SetVisible true) y al salir del campo lo oculta (SetVisible false). Opcional:
  sudo apt-get install -y xdotool para traer la ventana del teclado al frente.

6. Bluetooth (mensaje «Emparejar» en la Pi)

  La ventana maximizada puede tapar ese diálogo. Opciones:

  a) Modo teclado Bluetooth → «Bajar app (emparejar)», acepta en la Pi,
     luego «Pantalla completa».
  b) Emparejar la primera vez sin kiosco; ver CONEXION_BLUETOOTH_HID.txt.
  c) Por SSH con bluetoothctl (pair, trust, connect).
  d) GUIA_MODO_BLUETOOTH_HID_RPI.txt.

7. Variables opcionales

  RFID_REPO_ROOT — raíz del repo si no es la predeterminada.
  RFID_PYTHON — python del venv si no se llama .venv.

8. Mantenimiento

  Sin botón cerrar: pkill -f handheld_app (SSH) o teclado USB con atajos del escritorio.

9. Usuario final

  Usuario sin sudo para el día a día. systemctl/btmgmt sin contraseña: ver GUIA_MODO_BLUETOOTH_HID_RPI.txt (sudoers).
