    tipoUbicación (en datos de ejemplo de ellos)

    • "C" = Ubicado — el activo se escaneó en la ubicación que correspondía.

    • "N" o vacío / null = No ubicado — en esa toma aún no se escaneó en la ubicación (en inventario).

    En esta prueba básica no hay catálogo en vivo: solo se lista lo escaneado. La lógica C/U/N iría al integrar con el JSON/CSV de ejemplo que envíen.
