Punto 1: HID BLE + RFID (Raspberry Pi)
=====================================

Emparejamiento Pi ↔ Windows (pasos y comandos que funcionaron):
  → CONEXION_BLUETOOTH_HID.txt

Arranque automático del HID al encender la Pi (systemd):
  → AUTOSTART_HID.txt
  → systemd/rfid-hid-bt-up.service (discoverable + advertising al boot)
  → systemd/rfid-hid-bt-up-post.service (opcional: repetir bt-up tras el HID)
  → systemd/rfid-hid-gatt.service (+ rfid-hid-gatt.default)

Archivos:
- gattServer_upstream.py  — original HeadHodge (referencia).
- gatt_server_rfid.py     — sin demo M/volumen; send_text() + hilo opcional R200.
- hid_keys.py             — teclas HID (0-9, A-Z, a-z, Enter, Tab).

Copia a la Pi: carpeta pi_ble_hid completa y vendor/rfid_r200 (padre: rfid_inventory/vendor).

Solo teclado BLE (sin RFID):
  sudo python3 gatt_server_rfid.py
  Conecta Windows como antes. No hay envío automático hasta que llames send_text (p. ej. desde otro script en el mismo proceso) o actives RFID_PORT.

HID + lector R200 (mismo comando, con variables de entorno):
  export RFID_PORT=/dev/ttyUSB0
  export RFID_BAUD=115200
  export RFID_DEBOUNCE_S=0.35
  sudo -E python3 gatt_server_rfid.py

  sudo -E conserva RFID_*.

Si el sistema web usa Tab en vez de Enter, en gatt_server_rfid.py busca
  line = epc_hex + "\n"
y cámbialo a "\t".
